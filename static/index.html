ARCHITECTURE PRINCIPLE

AI can propose.
It cannot grant itself access.

Nemotron on Nebius Token Factory compiles the human task into a proposed capability set and chooses sandbox actions. A separate, deterministic Python policy gate authorizes or blocks every tool invocation.

Adversarial mode introduces an untrusted email and independently issues a labeled red-team tool probe, so blocked probes are never misrepresented as spontaneous model behavior. No real messages are sent or deleted.
